Cómo Entrar a la BIOS e Instalar Windows desde una USB

Instalar Windows desde cero es más fácil de lo que parece, pero antes hay que superar dos muros: la BIOS y el arranque desde la USB. Esta guía te lleva de la mano de la A a la Z, con las teclas exactas y sin rodeos.

👤 NagoKeys 📅 16 de septiembre de 2026 ⏱️ 6 min de lectura

En esta guía

  1. Crea una USB arrancable de Windows
  2. Entra a la BIOS o UEFI
  3. Cambia el orden de arranque
  4. Instalación limpia de Windows
  5. ¿Y si no arranca desde la USB?

Paso 1: Crea una USB arrancable de Windows

Antes de tocar la BIOS necesitas una USB de al menos 8 GB con el sistema dentro:

  1. Descarga la herramienta de creación de medios desde la web oficial de Microsoft.
  2. Elige "Crear un medio de instalación para otro PC".
  3. Selecciona idioma, edición y que la salida sea ISO o directamente a la USB.
  4. Espera a que termine de copiar (tarda unos minutos).

Paso 2: Entra a la BIOS o UEFI

Reinicia el PC y pulsa la tecla correspondiente a tu placa antes de que aparezca el logo principal. Las más comunes son:

Fabricante Tecla habitual
ASUS, Gigabyte, MSI Supr / Delete
HP Esc o F10
Lenovo, Dell, Acer F2
Portátiles con Windows 11 F12 (menú de arranque)

En Windows 11 también puedes llegar desde Configuración > Sistema > Recuperación > Inicio avanzado, reiniciar y elegir "Solución de problemas > Opciones avanzadas > Configuración de firmware UEFI".

Paso 3: Cambia el orden de arranque

  1. Dentro de la BIOS, busca el menú Boot.
  2. Localiza "Boot Priority" o "Boot Order".
  3. Pon tu USB en primer lugar (suele aparecer por su nombre o como UEFI: <marca>).
  4. Guarda los cambios con F10 y confirma.
  5. El PC debería arrancar desde la USB.

Paso 4: Instalación limpia de Windows

  1. Selecciona idioma y haz clic en Instalar ahora.
  2. Elige la edición que coincida con tu licencia (Home o Pro).
  3. Pulsa "Instalación personalizada" para formatear desde cero.
  4. Borra las particiones del disco antiguo (cuidado con tus datos) y crea una nueva.
  5. Deja que Windows copie los archivos; el PC se reiniciará varias veces.

Cuando termine, tendrás un sistema limpio. Después de instalar, toca activar Windows con tu clave para tener el sistema totalmente original, sin marca de agua y con todas las funciones.

¿Y si mi PC no arranca desde la USB?

  • Desactiva el Secure Boot temporalmente si el sistema no lo detecta.
  • Prueba el modo Legacy/CSM si tu placa es antigua.
  • Usa un puerto USB trasero de la placa.
  • Regenera la USB con la herramienta oficial de Microsoft.
💡

Consejo: si tu PC no reconoce el arranque USB, revisa antes la compatibilidad de tu procesador y placa base para descartar problemas de hardware.
