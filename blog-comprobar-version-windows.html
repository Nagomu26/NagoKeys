Cómo Saber si Tienes Windows Home o Pro (y por qué importa)

Comprar la clave equivocada es el error más caro que puedes cometer: si tienes Pro y compras una Home, tu sistema te va a pedir perpetually una clave nueva. Te enseñamos a mirar tu versión en 10 segundos para comprar exactamente la que necesitas.

Las tres formas más rápidas de verlo

Opción 1: el comando winver (10 segundos)

Pulsa Windows + R, escribe winver y pulsa Enter. Se abrirá una ventana con el nombre exacto de tu edición, por ejemplo Windows 11 Pro o Windows 11 Home, junto al número de compilación y la fecha de instalación.

Opción 2: Ajustes del sistema (más detalles)

Ve a Configuración > Sistema > Información. En el bloque Especificaciones del dispositivo verás la edición de Windows, el procesador, la RAM instalada y el tipo de sistema. Es la pantalla que además te sirve para comprobar si tu equipo cumple los requisitos de Windows 11.

Opción 3: el estado de activación

En Configuración > Sistema > Activación Windows te indica si el sistema está activado, qué edición está instalada y, si hay clave, cuál es. Si aquí pone Windows 11 Pro sin activar, ya sabes qué clave necesitas.

💡

No te fíes del nombre de la carpeta. Ni Windows ni Windows.old en la unidad C: te dicen qué edición está instalada ahora, no la que quieres.

Qué te pierdes si compras la edición equivocada

Si te equivocas al comprar, Windows acepta la clave y cambia la edición, pero eso no siempre es lo que quieres: una clave Home en un equipo Pro lo deja en Home y te hace perder funciones. Estas son las diferencias reales entre las dos ediciones:

Función Home Pro
Escritorio remoto No Sí
BitLocker (cifrar el disco) No Sí
DirectX 12 Ultimate No Sí
Máquinas virtuales (Hyper-V) No Sí
Unirse a un dominio de empresa No Sí
Windows Update Sí Sí
Office, juegos y navegación Sí Sí

Nota importante: ninguna de las dos ediciones es mejor para jugar. Para gaming son prácticamente equivalentes. La diferencia real está en uso profesional: si trabajas con datos sensibles, te conectas a un ordenador de la oficina o quieres cifrar tu disco, necesitas Pro. Lo explicamos a fondo en la comparativa Home vs Pro para gaming.

Qué versión necesitas en la práctica

  • Windows 11 Home si: juegas, navegas, usas Office, ves vídeos y quieres las actualizaciones de Windows.
  • Windows 11 Pro si: accedes a tu trabajo de forma remota, necesitas BitLocker, quieres montar máquinas virtuales o te conectas a un servidor de empresa.
  • Windows 11 Home ya instalado se convierte en Pro introduciendo una clave Pro: Windows hace el upgrade de edición automáticamente, sin formatear y sin perder tus programas ni tus archivos.
💡

Home y Pro se pueden cambiar en ambos sentidos. Microsoft permite subir de Home a Pro con una clave Pro, y bajar de Pro a Home con una clave Home. Lo que no se puede es instalar una edición superior con una clave inferior: si tienes Pro y metes una clave Home, el equipo baja a Home.

Si ya compraste la edición equivocada

Depende de qué te haya pasado exactamente:

  • Compraste Pro para un equipo Home: no hay ningún problema. Introduces la clave Pro en Configuración > Sistema > Activación > Cambiar clave de producto y Windows actualiza la edición a Pro automáticamente. Tus programas y tus archivos se quedan como estaban.
  • Compraste Home para un equipo Pro: aquí sí hay una pérdida real. Windows hace downgrade a Home y pierdes las funciones exclusivas de Pro (Escritorio remoto, BitLocker, Hyper-V, dominio de empresa), aunque evitarás el aviso de activación. Si necesitas esas funciones, recupera la clave Pro.
